# 壁掛けフレーム（Kindle Paperwhite 第7世代・Bambu Lab A1 mini）

横置きで、Kindle のロゴ（充電端子・電源ボタンのある辺）が右側に来る向きです。
ケーブルは**右下の角から下向きに**出ます。

| 部品 | ファイル | 大きさ | 印刷の向き |
|---|---|---|---|
| 額の本体 | `stl/frame.stl` | 178 × 151.6 × 14 mm | **前面（画面側）を下**。サポートなし |
| 裏ぶた | `stl/back.stl` | 174.8 × 148 × 2.9 mm | そのまま（外側の面が下） |
| お試し | `stl/fit_test.stl` | 178 × 151.6 × 3 mm | 前面を下。20 分ほど |

## 仕組み

```
  ┌──────────────────────────────────────┐
  │  ┌────────────────────────┐   Kindle │ ║ ← 右の溝（幅 約5.6mm）
  │  │        画面の窓        │   ロゴ側 │ ║    FPC リボンを下へ通す
  │  │                        │       ●──┼─╢ ← micro-USB 端子に 90° プラグ
  │  └────────────────────────┘          │ ║    （端子の上に電源ボタン用スリット）
  └──────────────────────────────────────┘ ║
                                       [メス基板] ← 右下角のポケット 16×11mm
                                          ↓  下面の差し口からケーブル
```

- 端子に挿した薄い FPC（フラットケーブル）を溝に沿って下へ折り、右下のポケットに受け側の基板を収めます。
  普通の USB ケーブルはその基板に挿すので、プラグの出っ張りは額の外（下）だけです。
- 電源ボタンは右の壁の縦スリット（端子の 6〜32mm 上）から、つまようじなどで押せます。
- 壁へは、裏ぶたの鍵穴 2 つ（間隔 90mm）を壁のねじ 2 本に引っかけます。

## 買うもの

### FPC 延長ケーブル（必須）

条件: **micro-USB オス 90°（L字）→ メス**、フラットリボン、**長さ 10〜20cm**、
メス側の基板が **幅 16mm × 奥行 11mm 以内**（厚みは 5mm 程度まで）。

| 候補 | 備考 |
|---|---|
| Amazon「Short Flat Slim Thin Ribbon FPC Micro USB 90 Degree Angled up Male to Micro USB Female Receptacle (20CM)」（ASIN B07Q4WZX19） | 第一候補。20cm で長さに余裕あり（余りは溝の中で折り返す） |
| 同 5cm 版（B07Q8FCPFZ） | 短すぎて届かないので不可 |
| AliExpress「FPV FPC ribbon micro USB 90 degree」系（20 ピン式のプラグ・基板を選べるキット） | プラグの向き（上/下/左/右 90°）と受け側（micro-USB / USB-C メス）を選べる。USB-C メスにすれば今後のケーブルが楽 |

- 「90° Angled **up/down**」どちらでも使えます（FPC は 1 回折り目を付ければ向きを変えられる）。
  端子に挿したときリボンが**画面と平行に下へ**向くように、45° に 1 回折ります。
- **付けたまま充電・通信できるか**を、ケースに入れる前に必ず確認。
- 注意: 受け側基板が大きい製品（20mm 超など）はポケットに入りません。届いたら寸法を測って、
  合わなければ `case.py` の `JACK_POCKET_W, JACK_POCKET_H` を変えて作り直してください。

### ねじ・その他

| 物 | 数 | 用途 |
|---|---|---|
| M3 × 8〜10mm **皿**タッピングねじ（樹脂用でも可） | 4 | 裏ぶたの固定 |
| 壁用ねじ（**頭の径 8mm 以下・軸 4mm 以下**、例: 3.5×25mm なべ）＋ 石膏ボード用アンカー | 2 | 壁掛け。90mm 間隔・水平に、壁から 3mm ほど出しておく |
| 両面テープ／瞬間接着剤（少量） | – | メス基板をポケットに固定 |
| （任意）薄いスポンジテープ 1mm | – | Kindle ががたつくとき裏ぶたの帯に貼る |
| USB 電源（5V 1A 以上）と、受け側に合うケーブル | – | 常時給電 |

## 印刷（Bambu Studio）

- 材料: PLA（マット黒・白が額らしい）。日の当たる窓際なら PETG。
- 積層 0.2mm、壁 3 周、インフィル 15%、**サポートなし**。
- **ブリム・スカートは切る**（本体は 178mm で A1 mini の 180mm ぎりぎり）。プレートの中央に置く。
- 本体は前面を下に（`frame.stl` はそのままの向き）。テクスチャ PEI プレートなら前面がシボ仕上げになってきれい。
- 時間の目安: 本体 約 4〜5 時間、裏ぶた 約 2 時間。

### まず `fit_test.stl` を印刷する

画面の位置は写真からの推定値なので、20 分のお試しで確かめます。

1. Kindle をお試しの上に置き、**窓の中に表示部がちょうど収まり、黒い縁が見えない**か見る。
2. Kindle の外形が壁の根元（1mm 分）にきつすぎず入るか。
3. ずれていたら `case.py` 上部の数字を直して `python case.py` で作り直し:
   - 窓が左右にずれる → `SCREEN_LEFT`、上下にずれる → `SCREEN_BOTTOM`
   - 窓が小さい／大きい → `WINDOW_MARGIN`
   - きつい／ゆるい → `FIT`

```bash
pip install manifold3d trimesh numpy
python case.py           # stl/ を作り直す
python render_preview.py # 確認用の画像（任意, Pillow が必要）
```

## 組み立て

1. FPC のプラグを Kindle の micro-USB 端子に挿し、リボンを下向きに折る。
2. Kindle を画面を下にして額に入れる（ロゴ側が右）。リボンを右の溝に沿わせて下へ。
3. メス基板を右下のポケットに、差し口が**下面の穴**に向くように入れ、テープか接着剤で固定。
   余ったリボンは溝の中でたたむ。
4. 裏ぶたをはめ、皿ねじ 4 本で留める（締めすぎない）。
5. 下の差し口に USB ケーブルを挿して充電・表示を確認。
6. 壁のねじ 2 本に鍵穴を通して下へ引っかける。

電源ボタンは右の側面のスリットから細い棒で押します（Dashboard 停止のとき）。
スリットとボタンの位置が合わないときは `BUTTON_SLOT`（端子の中心から上へ何 mm〜何 mm）を調整。

## 変えられる主な寸法（`case.py` の先頭）

| 名前 | 既定 | 意味 |
|---|---|---|
| `W` | 178 | 全体の横幅（A1 mini は 180 まで） |
| `BORDER_BOTTOM`, `BORDER_TOP` | 16, 18 | Kindle の下・上の額の幅 |
| `FRONT_T` | 2.0 | 前面の厚さ |
| `FIT` | 0.3 | Kindle の周りのすき間 |
| `SCREEN_LEFT`, `SCREEN_BOTTOM` | 19.0, 13.1 | 表示部の位置 |
| `JACK_POCKET_W`, `JACK_POCKET_H` | 16, 11 | メス基板のポケット |
| `KEYHOLE_SPACING` | 90 | 壁ねじの間隔 |
