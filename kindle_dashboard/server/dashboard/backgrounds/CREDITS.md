# 標準の背景写真（/fire）

すべて Wikimedia Commons の **パブリックドメイン** または **CC0**（著作権表示なしで自由に使える）の写真。
画面に合わせて 1600×1000 に切り抜き・縮小してある。差し替えたいときは NAS の `config/backgrounds/` に
同じ名前で置けば、そちらが優先される（[FIRE_SETUP.md](../../../FIRE_SETUP.md) の「背景を写真にする」）。
