## 部品の変更の経緯

| 変更 | 理由 |
|---|---|
| ポリスイッチ RXEF090 → MF-RX110/72 | RXEF090 が売り切れ。外形も小さすぎた |
| 逆接保護 1N5819 → SB340LS | ポリスイッチはトリップまで 2.2A 流れうるため 3A 品に |
| TVS P6KE20A → P4KE15A＋P4KE6.8CA の直列 | 秋月で買えるものに |
| 入力の抵抗 2.2k → 3.3k | 35V での発熱を抑える |
| R2 18k → 10k | 手持ちに合わせた |
