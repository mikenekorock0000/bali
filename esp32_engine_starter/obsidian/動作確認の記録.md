# 動作確認の記録

[[HIJET MONITOR]] ／ 関連：[[トラブルシューティング]]・[[組み立て]]

## 机の上（ESP32 単体、USB 給電）2026-10-25

単体で試すときは、ESP32 の **VP（GPIO36）と 3V3 をジャンパ線でつなぐ**（ACC の入力が浮くと ON/OFF を繰り返すため）。VP を GND にすると ACC ON、D33 を GND にするとドア開。

| 確認 | 結果 |
|---|---|
| ビルド・USB 書き込み（PlatformIO） | ✅ |
| 起動とシリアル出力 | ✅ BME280・MPU6050 は「なし」（未接続なので正常） |
| 設定モードに入る・設定画面を開く | ✅（途中でバグを直した。[[トラブルシューティング#設定モードの Wi-Fi にすぐ切れる]]） |
| テザリングにつながる・ntfy に「起動しました」 | ✅ |
| 状態の送信（`[state] 送信 200`） | ✅ |
| ダッシュボードの表示 | ✅（トピック名の入れ違いを直した） |
| 署名付きの指示（ブザーを鳴らす） | ✅ `署名の判定 0` |
| ACC・ドアの入力がダッシュボードに出る | ✅ |
| 侵入・盗難の通知 | ⏸ ビーコン未入手のため未確認（登録しないと警戒が始まらない） |
| 遠隔更新（1.1.0 → 1.2.0） | ✅ 起動後 1 分ほどで「ファームウェアを更新しました」 |
