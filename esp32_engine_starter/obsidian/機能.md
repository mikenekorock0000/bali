# 機能

[[HIJET MONITOR]] ／ 関連：[[初期設定と使い方]]・[[ファームウェア]]

## 通知の考え方

ドアや ACC が変わるたびには通知しない。**キー（ビーコン）が近くにないときの異常**だけを通知する。
普段の乗り降りでいちいち通知が来ないようにするため。ビーコンを登録するまでは、キーが「未確認」のままで、警戒は始まらない。

## 機能の一覧

| 機能 | 内容 | 必要なもの |
|---|---|---|
| 自動ロック | キーが離れたら、ドアが閉まっていれば施錠信号を 400ms 出す。開いていたら、閉まった時点で施錠 | ビーコン、施錠信号・ドア信号の配線 |
| 侵入検知 | キーが離れているのにドアが開いた → 緊急通知（ブザーは任意） | ドア信号 |
| 揺れ検知 | 警戒中に車体が揺れた（0.12g 超）→ 通知。眠っている間は働かない | MPU6050 |
| ドアの開けっぱなし | キーが無いまま、ドアが 5 分開いている → 通知 | ドア信号 |
| バッテリー | 11.8V が 1 分続く → 低電圧の通知。始動時に 9.6V 未満 → 劣化の目安。走行中に 13.0V 未満 → 充電不良。11.5V 以下でエンジン停止中なら省電力で休止 | 基板のみ |
| OBD-II | 水温 105℃ 超、エンジン警告灯 → 通知。回転数でエンジン稼働を判定 | OBD-II ケーブル |
| 稼働時間・オイル | エンジン稼働時間を積算し、150 時間でオイル交換の通知 | OBD か電圧 |
| 走行記録 | 走行ごとの時間・距離・最高速度と駐車位置（地図リンク） | GPS |
| 車内環境 | 45℃ 超・−5℃ 未満 → 通知 | BME280 |
| 凍結の注意 | 朝 5〜9 時に車内が 1℃ 以下 → 通知（1 日 1 回） | BME280 |
| 毎日の報告 | 20 時に状態をまとめて通知 | — |
| 盗難の検知 | キーが無いのに ACC が入った（30 秒）→ 緊急通知し、位置を 3 分ごとに通知（追跡）。駐車中は 15 分ごとに GPS で位置を確かめ、150m 以上動いていたら通知 | ビーコン、GPS |
| 点検の予定 | 車検・タイヤ交換などを日付か距離で登録。30・7・1・0 日前、距離は 500・100・0km 前に通知 | 距離は GPS |
| 駐車モード | キーが離れて 10 分たったら深く眠る。ドア・ACC ですぐ起き、15 分ごとに起きて指示と電圧を見る | — |
| 見張り | 固まったら 30 秒で再起動し、理由を通知 | — |
| 遠隔更新 | ダッシュボードからファームウェアを送って更新。新しい版が 10 分以内に ntfy と通信できなければ前の版に戻る | — |
| ダッシュボード | 電圧・車内温度の 24 時間グラフ、状態、駐車位置の地図、通知の履歴、操作ボタン | — |

解錠の機能はない（防犯のため）。

## 駐車モードと消費電流

| 項目 | 内容 |
|---|---|
| 眠る条件 | キーが離れている・ACC OFF・ドアが閉・処理中のものがない、が 10 分続く |
| すぐ起きる | ドアが開いた（15 秒以内にキーが見つからなければ侵入）、ACC ON |
| 時間で起きる | 15 分ごと。指示・電圧・報告を確かめて、また眠る（最長 45 秒） |
| 眠る前に止めるもの | Wi-Fi・BLE、GPS（待機命令）、センサー、出力とブザー（LOW に固定） |

| 状態 | 12V 側の見積もり（**未実測**） | 1 日あたり |
|---|---|---|
| 駐車モードなし | 50〜65mA | 1.2〜1.6Ah |
| 駐車モード | 5〜13mA | 0.12〜0.3Ah |

取り付けたら、12V の線にテスターを直列に入れて、眠っている間の電流を測る。
