# ハードウェア

[[HIJET MONITOR]] ／ 関連：[[部品表]]・[[組み立て]]

## 基板（v4）

| 項目 | 内容 |
|---|---|
| 外形 | 98 × 90 mm、2 層、M3 取付穴 ×4（JLCPCB の 100mm 以内の価格） |
| ESP32 | DevKit V1 30 ピン（HW-394、列間 25.4mm）を**直接はんだ付け**。振動でソケットが緩むのを防ぐため。下の隙間は約 2.5mm で、下に部品はない |
| 部品 | 出力の TVS（表面実装 4 個）以外はリード部品。抵抗・ダイオードは立てて実装 |
| 作り方 | `hardware/gen_pcb.py` から生成（手で描いていない）。回路図ファイルはなく、`netlist.txt` が回路図の代わり |
| 検証 | DRC・ピン照合（68 組）・部品の収まり・回路シミュレーション（ngspice）・製造データ、すべて問題 0 |
| USB の向き | DevKit の USB 端子は基板の内側（「USB cable keep clear」の側）を向く。ケースの外に出せないのは設計の見落とし。対策は遠隔更新・USB 延長ケーブル。作り直すなら v5 で向きを変える |

## 回路のブロック

| ブロック | 内容 |
|---|---|
| 電源 | J1 +12V → F1 ポリスイッチ MF-RX110/72（1.1A・72V）→ D1 SB340LS（逆接保護 3A）→ D2 P4KE15A ＋ D12 P4KE6.8CA（直列 TVS、約 30V に抑える）・C1 100µF 50V → U1 M78AR05-1（DC-DC 5V 1A、入力 6.5〜32V）→ C2 100µF・C3 0.1µF → ESP32 の VIN |
| 電圧測定 | F1 の後の 12V → R1 100k / R2 10k → GPIO34。C4 0.1µF、D3 BAT43 で 3.3V にクランプ。12V で約 1.09V |
| 絶縁出力 ×4（J2） | GPIO25/26/27/32 → 330Ω → PC817（U2〜U5）。トランジスタ側を J2 に出す。各 50mA 以下。端子間に SMBJ45CA（D8〜D11） |
| 絶縁入力 ×3（J3） | IN+ → 3.3k → PC817（U6〜U8）→ IN−。1N4148 で逆電圧保護。受光側は 10k で 3.3V にプルアップし、信号ありで LOW |
| OBD-II（CAN） | MCP2562FD（U9）。STBY は R15 10k で既定は待機（車の CAN に送信しない）。GPIO4 を LOW にしたときだけ動作。終端抵抗なし |
| ブザー | GPIO13 → 1k → 2SC1815 → 5V 自励式ブザー。R14 10k で起動時 OFF、D7 で逆起電力を吸収 |

## 端子

端子台はすべて 5.08mm ピッチ。

| 端子 | ピン | つなぐ先 |
|---|---|---|
| J1 | +12V / GND / OUT | +12V＝常時電源（車両側にもヒューズ）、GND＝ボディアース、OUT＝ヒューズの後の 12V（入力の IN+ 用） |
| J2 | LOCK − / + | 施錠信号（GND に落とすと施錠するタイプ）。＋を信号線、−を GND。**逆につながない**（PC817 は逆電圧 6V まで） |
| J2 | OUT2〜4 − / + | 汎用。作業灯などはリレーモジュールの入力へ |
| J3 | IN1 + / − | ドア（開くと GND に落ちるタイプ）：IN+ を J1 の OUT、IN− をドアの信号線 |
| J3 | ACC + / − | ACC（キー ON で 12V）の線を ACC+、ACC− を GND |
| J3 | IN2 + / − | 予備 |
| J7 | CAN H / L / G | OBD-II の 6 番（CAN-H）、14 番（CAN-L）、4・5 番（GND） |
| J8 | GND / 3V3 / GPS RX / GPS TX（上から） | UART の GPS（BN-220 など）。GPS RX の端子をモジュールの RX に、GPS TX をモジュールの TX に |
| J4 | GND / 3V3 / SCL / SDA（上から） | BME280・MPU6050（3.3V 品） |

## ESP32 のピン割り当て

| GPIO | 用途 |
|---|---|
| 25 / 26 / 27 / 32 | 出力 LOCK / OUT2 / OUT3 / OUT4 |
| 33 | IN1 ドア（眠りから起こす） |
| 35 | IN2 予備 |
| 36（VP） | IN3 ACC（眠りから起こす）。300ms のチャタリング除去 |
| 34 | 電圧測定（ADC1） |
| 18 / 19 / 4 | CAN TX / RX / STBY |
| 13 | ブザー |
| 21 / 22 | I2C SDA / SCL |
| 17 / 16 | GPS への TX / GPS からの RX（9600bps） |
| 0 | BOOT ボタン（3 秒押すと設定モード） |

## 車載の保護と、守れないもの

| 想定 | 対策 |
|---|---|
| バッテリーの逆接続 | D1 SB340LS |
| ショート・過電流 | F1 ポリスイッチ（自己復帰） |
| 電源のサージ | D2＋D12 で約 30V 以下（DC-DC の上限 32V） |
| 出力の配線のサージ | SMBJ45CA で 72.7V 以下（PC817 の上限 80V） |
| 入力の配線のサージ | 3.3k で電流を制限（35V でも抵抗の発熱は短時間の許容内） |
| 振動 | ESP32 の直付け、背の低い電解コンデンサ、M3 スペーサー |

守れないもの：24V でのジャンプスタート（F1 が切れて止まる）、抑制のないロードダンプ、出力の逆接続、CAN のサージ（MCP2562 内蔵の保護だけ）。

## 決まり

**12V（J1）と USB を同時につながない。** USB で書き込むときは 12V を外す。
