# 初期設定と使い方

[[HIJET MONITOR]] ／ 関連：[[ダッシュボード]]・[[ファームウェア#設定モード]]

## ntfy（スマホ）

1. App Store で **ntfy** を入れる。アカウントは要らない。
2. 「＋」で**通知のトピックだけ**を購読する。サーバーは既定の ntfy.sh のまま。
3. 通知を許可する。

## 設定モード

1. ESP32 の BOOT ボタンを **3 秒**押す（未設定なら起動しただけで入る）。
2. **iPhone のテザリングを OFF にする**（テザリングを出しているスマホは、別の Wi-Fi につなげない）。
3. Wi-Fi「`HIJET-SETUP-A318`」につなぐ。パスワード `hijet-setup`。
4. 画面が開かなければ `http://192.168.4.1`。

| 項目 | 入れるもの |
|---|---|
| Wi-Fi 1 | 車内で使う Wi-Fi（iPhone のテザリング）。2.4GHz だけ。iPhone は「互換性を優先」を ON |
| Wi-Fi 2 | 予備（自宅など）。つながらないときは 1 と 2 を 20 秒ごとに交互に試す |
| ntfy | サーバー `https://ntfy.sh`、3 つのトピック |
| 暗証番号 | 数字 4〜8 桁 |
| OTA パスワード | 8〜32 文字 |
| キー | 「近くの BLE 機器を表示」で選ぶ（1 回目は空のことがあるので、もう一度押す） |
| 点検の予定 | 1 行に 1 件。「車検 2027-05-20」「タイヤ交換 45000km」 |
| 電圧の補正係数 | テスターの値 ÷ 表示の値（0.8〜1.2） |

「指示の鍵」の枠で暗証番号を入れて「表示」を押すと、ダッシュボードに入れるもの（サーバー・3 つのトピック・鍵）がまとめて出る。
保存すると再起動する。設定を変えないなら、保存せずに閉じてよい（10 分で終わる）。

## 指示の一覧

ふだんはダッシュボードのボタンから送る（署名付き）。ntfy アプリから手で `暗証番号 指示` と送れるのは `status`・`state`・`scan`・`beep`・`lock` だけ。

| 指示 | 内容 |
|---|---|
| `status` | 今の状態を通知 |
| `state` | ダッシュボードに状態を送る（通知なし） |
| `scan` | 近くの BLE 機器の一覧 |
| `lock` | 今すぐ施錠 |
| `pause 60` / `pause` / `resume` | 自動ロックを 60 分 / 再開まで止める、再開 |
| `autolock on\|off` | 自動ロック |
| `alarm on\|off` | 侵入・揺れの通知 |
| `siren on\|off` | 侵入時のブザー（初期値 off） |
| `park on\|off` | 駐車モード（初期値 on） |
| `beep` / `silence` | ブザーを鳴らす / 止める |
| `track on\|off` | 追跡 |
| `oilreset` | オイル交換を記録 |
| `setup` | 設定モード |
| `ota <SHA-256>` | 遠隔更新（ダッシュボードの「ファームウェアを更新」が送る） |

## Ottocast の GPS を使う（任意）

Ottocast に GPS があれば、**GPSd Forwarder** などで NMEA を UDP の 10110 番、ESP32 の IP に送る。テザリングによっては機器どうしが通信できない。ACC OFF で切れるので、駐車中の移動の確認には J8 の GPS が必要。
