# 書き込みと更新

[[HIJET MONITOR]] ／ 関連：[[ファームウェア]]・[[トラブルシューティング]]

## パソコンの準備（Mac、済み）

1. VS Code を入れ、拡張機能で **Japanese Language Pack** と **PlatformIO IDE** を入れる。
2. git でリポジトリを持ってくる：コマンドパレット（Cmd+Shift+P）→ `Git: Clone` → `https://github.com/mikenekorock0000/bali.git`。
3. 左下のブランチを `claude/esp32-engine-starter-oy9iav` に切り替える。
4. 「ファイル → フォルダーを開く」で `esp32_engine_starter` を開く（`platformio.ini` がある階層）。

いまの置き場所：`/Users/mike/bali/esp32_engine_starter`

## 最新にする

「ソース管理 → … → **プル**」。左下に `2↓` などと出ていたら、取り込んでいない更新がある。
**プルしただけでは ESP32 の中身は変わらない。** 書き込みまでする。

## USB で書き込む（PlatformIO）

1. 12V を外して、ESP32 を USB でつなぐ。
2. アリのアイコン → esp32dev（または Default）→ **Upload**。
3. `Connecting...` で止まったら BOOT ボタンを押したままにし、書き込みが始まったら離す。
4. **Monitor** で様子を見る（115200bps）。**Upload and Monitor** でまとめてもよい。

`native` は PC 用のテストの環境。「Build」で一緒に動いて失敗していたので、既定から外した。

## Arduino IDE で書き込む

1. ボードマネージャの URL に `https://espressif.github.io/arduino-esp32/package_esp32_index.json` を足し、「esp32」の **2.0.17** を入れる。
2. ライブラリ：NimBLE-Arduino **1.4.3**、ArduinoJson **7.2.1**、Adafruit BME280 Library **2.2.4**。
3. `esp32_engine_starter.ino` を開く（フォルダ名は変えない）。
4. ボード **ESP32 Dev Module**、Partition Scheme **Minimal SPIFFS (1.9MB APP with OTA)**。

## 離れた場所から更新する

同じ Wi-Fi にいなくてよい。2026-10-25 に 1.1.0 → 1.2.0 で成功。

1. プルして **Build** だけ押す。`build/firmware.bin` にコピーされる（なければ `.pio/build/esp32dev/firmware.bin`。隠しフォルダは Cmd+Shift+. で見える）。
2. ダッシュボードの「**ファームウェアを更新**」で、そのファイルを選んで「送る」。
3. ESP32 は次に指示を読んだとき（30 秒ごと、休止中なら最大 15 分後）にダウンロードし、書き込んで再起動する。
4. 「起動しました（新しい版）」のあと、**1 分ほどして**「ファームウェアを更新しました」が届けば完了。

しくみ：
- ダッシュボードがファイルを ntfy の指示のトピックに添付し、署名付きの指示 `ota <SHA-256>` を付けて送る。
- ESP32 はダウンロードしながら SHA-256 を計算し、指示の値と一致したときだけ書き込む。
- 新しい版が 10 分以内に ntfy とやり取りできなければ、前の版に戻る。
- ntfy.sh の添付は 3 時間で消える。

## 同じ Wi-Fi にいるときの OTA

```
HIJET_OTA_PASS=設定画面の OTA パスワード pio run -e ota -t upload
```
見つからなければ `--upload-port <ダッシュボードに出る IP>` を付ける。iPhone のテザリングでは、つないだ機器どうしが通信できないことがある。（実機では未確認）
