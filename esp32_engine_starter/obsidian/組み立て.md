# 組み立て

[[HIJET MONITOR]] ／ 関連：[[ハードウェア]]・[[部品表]]・[[動作確認の記録]]

## 順番

1. **TVS（D8〜D11）を最初に**付ける。表面実装なので、片方のパッドにはんだを盛り、ピンセットで押さえて付け、反対側を付ける。向きはない。
2. 背の低い順：抵抗 → ダイオード → フォトカプラ・MCP2562 → セラミックコンデンサ → トランジスタ → ピンヘッダー（J4・J8）→ ポリスイッチ → 電解コンデンサ → ブザー → 端子台 → DC-DC。
3. ESP32 は最後。付ける前に電源を確かめる（下）。

## 向きのある部品

| 部品 | 向き |
|---|---|
| ダイオード D1〜D7・D2 | 立てて付ける。本体を丸いシルクの上に立て、**帯（カソード）を上**にして、折り返した足を「K」の四角いパッドへ |
| D12 P4KE6.8CA | 双方向なので、どちらでもよい |
| 電解コンデンサ C1・C2 | 長い足（＋）を「+」の四角いパッドへ |
| フォトカプラ U2〜U8（PC817） | **向きがある**。本体の 1 番ピンの丸印を四角いパッドに |
| M78AR05-1（U1） | 1 番ピン（Vin）を四角いパッドに |
| MCP2562（U9） | 1 番ピンの丸印（切り欠き側）を四角いパッドに |
| 2SC1815（Q1） | 左から E-C-B。シルクの半円が本体の丸い側 |
| ブザー BZ1 | ＋表示の足（長い足）を「+」の四角いパッドに |
| 抵抗 | どちらでもよい。立てて付ける |

抵抗の値の読み方：330R＝330Ω（R は小数点の代わり）。

## ESP32 を付ける前の確認（済み）

1. J1 の +12V と GND に 12V をつなぐ。
2. J5 の 15 番ピン（いちばん下、ESP32 の VIN）と GND の間が**約 5V**になることをテスターで確かめる。
3. 測る場所の図：`hardware/preview/testpoints.png`。

結果：問題なし（2026-10-24）。

## ESP32 のはんだ付け（次の工程）

1. 単体の試験で付けたジャンパ線（VP–3V3 など）を外す。
2. 最新のファームウェアを USB で書いておく（付けたあとは USB が通しにくい）。
3. 向きを 2 回確かめる。USB 端子が「USB cable keep clear」の側、VIN の列が左（J5）。
4. ピンの樹脂が基板に当たるまで押し付け、**四隅のピン**を先に付ける。浮いていないか確かめる。
5. 残りのピンを付け、となりのピンとのブリッジがないか確かめる。

## 12V での確認（次の工程）

12V と USB は同時につながない。様子はダッシュボードと ntfy で見る。

| 確かめること | やり方 | 期待する結果 |
|---|---|---|
| 起動 | J1 に 12V | ntfy に「起動しました」、ダッシュボードに状態 |
| 電圧 | ダッシュボードとテスターの値を比べる | ほぼ同じ。違えば設定画面の補正係数に「テスターの値 ÷ 表示の値」 |
| ブザー | ダッシュボードの「ブザーを鳴らす」 | 鳴る |
| ACC | J3 の ACC+ を J1 の OUT、ACC− を GND | ダッシュボードで ACC が ON |
| ドア | J3 の IN1+ を J1 の OUT、IN1− を GND に一瞬 | ダッシュボードでドアが開 |
| 施錠信号 | テスターの導通モードを J2 の LOCK + と − に当てて「今すぐ施錠」 | 一瞬導通する |

LED で見る方法：J1 の OUT → 1kΩ → LED（長い足が抵抗側）→ LOCK＋、LOCK− を GND。
