# ダッシュボード

[[HIJET MONITOR]] ／ 関連：[[初期設定と使い方]]

`dashboard/index.html` の 1 枚。サーバーは要らない。https://hijet-monitor.takuya-in.workers.dev で公開している（Mac のファイルを直接開いてもよい）。

## 設定（右上の「設定」）

| 欄 | 入れるもの |
|---|---|
| サーバー | `https://ntfy.sh` |
| 状態 / 通知 / 指示のトピック | 設定画面と**一字違わず**同じ |
| 指示の鍵 | 設定画面の「表示」で出る 32 桁 |
| 暗証番号 | 設定画面で決めたもの |
| アクセストークン | ntfy のアカウントを使うときだけ |

値はその端末のブラウザにだけ保存される。「別の端末用のリンクをコピー」で、サーバーとトピックだけを別の端末に渡せる（鍵は含めない）。

## 表示

| 表示 | 意味 |
|---|---|
| 右上「接続中…」 | 読み込み中 |
| 「ntfy に接続・状態待ち」 | ntfy にはつながったが、状態がまだ 1 件もない。トピック名の違いを疑う |
| 「動作中・〇分前」 | 正常 |
| 「駐車モードで休止中」 | 眠っている（15 分ごとに更新） |
| 「応答なし」 | 長く状態が来ていない |

バッテリー、状態（キー・ドア・警戒・ACC・温度など）、電圧と車内温度の 24 時間グラフ、駐車位置の地図、通知の履歴、点検の予定、前回の再起動の理由が出る。

## 操作

今すぐ施錠、状態を更新、自動ロックの停止・ON/OFF、警戒、サイレン、駐車モード、追跡、ブザー、オイル交換の記録、設定モードの開始、**ファームウェアを更新**。
状態は 30 秒ごとに読み直す。指示は ESP32 が 30 秒ごとに読む（休止中は最大 15 分後）。

## 置き場所

**Cloudflare Workers で公開**（プロジェクト名 `hijet-monitor`）：**https://hijet-monitor.takuya-in.workers.dev**

workers.dev は「Domains」で有効にしてある（最初は無効だった）。

| 設定 | 値 |
|---|---|
| リポジトリ | `mikenekorock0000/bali` |
| Production branch | `claude/esp32-engine-starter-oy9iav`（`main` にまとめたら変える） |
| Build command | なし |
| Deploy command | `npx wrangler deploy --name hijet-monitor --assets ./esp32_engine_starter/dashboard --compatibility-date 2026-10-01` |

push すると自動で公開し直される。公開されるのは `dashboard` フォルダの中だけ。
新しい URL では設定を入れ直す（「別の端末用のリンクをコピー」の先頭を新しい URL に変えて開き、鍵と暗証番号を入れる）。

ほかの置き場所：

個人の情報は HTML に書き込まないので、GitHub Pages や Netlify Drop に置いてもよい。スマホはホーム画面に追加するとアプリのように開ける。`index.html?demo` でデモ表示。

## 注意

- トピック名が漏れると、状態を読まれる。指示は鍵がないと作れない。
- 鍵が漏れたら、設定画面で「鍵を作り直す」。
- ntfy.sh は直近 12 時間ほどを保存。ESP32 は毎回 24 時間分の履歴を一緒に送る。
