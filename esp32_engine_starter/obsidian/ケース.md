# ケース

[[HIJET MONITOR]] ／ 関連：[[ハードウェア]]・[[組み立て]]

Bambu Lab A1 mini で印刷する、本体とふたの 2 つ。ファイルは `hardware/case/`（`case_base.stl`・`case_lid.stl`、生成スクリプト `gen_case.py`）。

| 項目 | 内容 |
|---|---|
| 大きさ | 本体 131×109×33.6mm（取り付けのつば込み）、組み立てた高さ 36.1mm |
| 材料 | **PETG**（車内の熱で PLA は変形する） |
| 印刷 | サポートなし。0.2mm、壁 3 周以上、インフィル 20〜25% |
| 基板の固定 | M3×10 を柱の下穴（2.6mm）に直接ねじ込む |
| ふたの固定 | 角の耳を M3×10 で 4 か所 |
| 車への取り付け | 左右のつばの長穴（4.5mm）に M4 か結束バンド |
| 電線の出口 | 壁の切り欠き：上＝J1 電源、下＝J7 CAN、左＝J2 出力・J3 入力、右＝センサー。ふたの舌で上側をふさぎ、高さ約 8mm のすき間が残る |
| ボタン | ふたの長穴から、つまようじで BOOT・EN を押す（位置は推定） |

注意：
- USB はケースの外に出ない。更新は遠隔更新（[[書き込みと更新#離れた場所から更新する]]）。
- BME280 と GPS はケースの外に出す。
- 寸法は計算だけで、実物では未確認。まず 1 回印刷して合わせる。
