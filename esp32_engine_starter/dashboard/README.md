# ダッシュボード

ESP32 が ntfy の「状態のトピック」に送る状態（JSON）を読んで、ブラウザでグラフィカルに表示する 1 枚の HTML です。
サーバー側のプログラムはいらず、`index.html` を置くだけで動きます。家からでも外出先からでも見られます。

| 表示 | 内容 |
|---|---|
| バッテリー | 今の電圧（色で良し悪し）、エンジン、前回始動時の電圧 |
| 状態 | キー（近く・離れている）、ドア、警戒、自動ロック、駐車モード、ACC、車内温度、水温・回転数、警告灯、稼働時間とオイル交換まで、Wi-Fi |
| グラフ | 電圧と車内温度の 24 時間（15 分ごと）。タップで値を表示 |
| 駐車位置 | 最後に測位した位置の地図（OpenStreetMap）と Google マップへのリンク |
| 通知の履歴 | 通知のトピックの直近 24 時間 |
| 盗難・点検 | 追跡中の警告、点検の予定（残り日数・距離）、前回の再起動の理由 |
| 操作 | 追跡の開始・終了、施錠、自動ロックの停止・再開・ON/OFF、警戒・サイレン・駐車モードの ON/OFF、ブザー、オイル交換の記録、設定モードの開始 |

状態は 30 秒ごとに読み直します。駐車モードで休止中は、ESP32 が 15 分ごとに起きたときに状態が更新され、操作もそのときに実行されます。

## 使い方

1. `index.html` をどこかに置いて開く（下の「置き場所」）。
2. 右上の「設定」で、ESP32 の設定画面で入れたものと同じ値を入れる：ntfy のサーバー、状態・通知・指示のトピック、**指示の鍵**（ESP32 の設定画面で暗証番号を入れて「表示」を押すと出る）。ntfy のアカウントを使うならアクセストークンも。値はその端末のブラウザにだけ保存されます。
3. 別の端末でも開くときは、設定の「別の端末用のリンクをコピー」で作ったリンクを開くと、サーバーとトピックが入ります（鍵・暗証番号・トークンは含めないので、その端末で入れる）。

ESP32 が無くても見た目を確かめられるよう、`index.html?demo` で開くとデモの値を表示します。

## 置き場所

`index.html` には個人の情報（トピック名・暗証番号）を書き込まないので、公開の場所に置いてもかまいません（値は開いた端末のブラウザに保存されます）。

- **GitHub Pages**：リポジトリの Settings → Pages で、このブランチを公開すると `https://<ユーザー名>.github.io/<リポジトリ名>/esp32_engine_starter/dashboard/` で開けます（非公開のリポジトリでは有料プランが必要）。
- **Netlify Drop など**：`dashboard` フォルダをブラウザにドラッグするだけで公開できるサービス。
- **パソコンだけで見る**：`index.html` をダブルクリックして開いてもよい。

スマホではホーム画面に追加すると、アプリのように開けます。

## 注意

- **トピック名が漏れると、状態を読まれたり、指示を送られたりします。**
  - ntfy.sh のトピックは、名前を知っている人なら誰でも読み書きできます。
  - ダッシュボードの指示には、時刻と「指示の鍵」による署名を付けています。トピックを読まれても、鍵を知らなければ指示を作れず、読んだ指示を送り直しても使い回しとして無視されます。鍵は人に見せないでください。漏れたら、ESP32 の設定画面で「鍵を作り直す」を選んで保存します。
  - トピック名は長く推測されないものにし、リンクを人に渡さないでください。
  - より安全にするには、ntfy のアカウント（アクセス制限付きのトピック）か、自分で立てた ntfy サーバーを使い、アクセストークンを設定します。
- **ntfy.sh が保存するのは直近 12 時間ほどです。** ESP32 は毎回 24 時間分の履歴を一緒に送るので、グラフは最新の状態だけで描けます。履歴は ESP32 の電源を切ると消えます。
