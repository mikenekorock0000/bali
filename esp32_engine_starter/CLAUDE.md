# このプロジェクト（HIJET MONITOR）で作業するときの決まり

- 変更をコミットしたら、`obsidian/履歴.md` のその日の見出し（なければ作る、新しい日付を上に）に 1 行足す。
  ファームウェアの版を変えたら、行の先頭に版を書く（例：「1.2.1：…」）。
- 試験の結果や、起きた問題と直し方が分かったら、`obsidian/動作確認の記録.md`・`obsidian/トラブルシューティング.md` も直す。
- 状況が変わったら、`obsidian/HIJET MONITOR.md` の「今の状況」と `obsidian/既知の課題と今後.md` も直す。
- ファームウェアの動きを変えたら、`src/config.h` の `FW_VERSION` を上げる（遠隔更新で版の違いが分かるように）。
- ノートは日本語の平易な文で書き、ノート間は `[[ノート名]]` でつなぐ。
