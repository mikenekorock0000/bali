# 基板（ESP32 DevKit V1 30ピン キャリア）

**ESP32 DevKit V1 互換（30 ピン、HW-394、列間 25.4mm）**を挿して使う、リード部品だけの 2 層基板です。
38 ピンの ESP32-DevKitC はピン配置が違うので挿せません。

![基板プレビュー](preview/top.png)

| 項目 | 内容 |
|---|---|
| 外形 | 92 × 70 mm、角に M3 取付穴 ×4 |
| 部品 | すべてリード部品。抵抗・ダイオードは足の間隔 5.08 mm で立てて実装。背の低い部品（MCP2562 など）は ESP32 ボードの下に置く |
| 層 | 2 層（両面に GND ベタ） |
| 最小パターン幅 / 間隔 | 0.4 mm / 0.3 mm（電源系は 1.0 mm） |
| 最小穴径 | 0.4 mm（ビア） |
| 検証 | DRC・ピン照合・部品の収まり・回路シミュレーション・製造データ照合すべて合格。詳しくは [VERIFICATION.md](VERIFICATION.md) |

## 発注するファイル

- **`hijet_starter_gerber.zip`** … ガーバー＋ドリル一式。DigiKey など、基板製造サービスにそのままアップロードします。
- 発注時の設定：2 層、FR-4、板厚 1.6 mm、銅厚 1 oz、表面処理は HASL（鉛フリー）、レジストは緑、シルクは白。

> **発注前に必ず確認してください。** `hijet_starter_1to1.pdf` を**原寸（100%・拡大縮小なし）**で印刷し、
> 実物の ESP32 ボードのピンが J5・J6 の穴の位置に合うことを確かめてください。
> 列の間隔 25.4 mm は、購入したボードをノギスで測った値（外側どうし 26.0 mm）と一致しています。

## 回路

| ブロック | 内容 |
|---|---|
| 電源 | J1「+12V」→ F1 ポリスイッチ 0.75A（自己復帰型ヒューズ）→ D1 1N5819（逆接保護）→ D2 P6KE22A（サージ吸収）・C1 100µF → U1 OKI-78SR（5V）→ C2 100µF・C3 0.1µF → ESP32 の 5V ピン |
| 電圧測定 | ヒューズの後ろの 12V → R1 100k / R2 18k で分圧 → GPIO34（16V で 2.44V＝ADC の精度のよい範囲内）。C4 0.1µF でノイズ除去、D3 BAT85 で 3.3V を超えないようクランプ |
| 絶縁出力 ×4 | GPIO25 / 26 / 27 / 32 → 330Ω → PC817C（U2〜U5）の LED。トランジスタ側を J2 に出す（ESP32 とは電気的に絶縁、各 50mA 以下） |
| 絶縁入力 ×3 | J3 の IN+ → 2.2k → PC817C（U6〜U8）→ IN−。1N4148 で逆電圧を保護。出力は GPIO33 / GPIO35 / GPIO36（10k で 3.3V にプルアップ、信号ありで LOW）。3ch 目は ACC（キー ON）検知用 |
| OBD-II（CAN） | MCP2562（U9）。VDD=5V、VIO=3.3V。TXD=GPIO18、RXD=GPIO19。STBY は R15 10k で 3.3V に引いて**既定は待機（車の CAN に一切関与しない）**、GPIO4 を LOW にしたときだけ動作。CAN-H / CAN-L を J7 へ（終端抵抗は付けない） |
| ブザー | GPIO13 → R13 1k → 2SC1815 → 5V 自励式ブザー。R14 10k で起動時は確実に OFF、D7 1N4148 で逆起電力を吸収 |
| GPS | J8：GND / 3V3 / GPS RX（GPIO17 から）/ GPS TX（GPIO16 へ） |
| I2C | J4：GND / 3V3 / SCL(GPIO22) / SDA(GPIO21)。0.96 インチ OLED（SSD1306）モジュールと同じピンの並び |

## 端子の使い方

| 端子 | ピン | つなぐ先 |
|---|---|---|
| J1 | +12V | ヒューズ電源（常時電源）。車両側にもヒューズを入れる |
|  | GND | ボディアース |
|  | 12V OUT | ヒューズ通過後の 12V（予備入力の IN+ 用） |
| J2 | LOCK + / − | 車両の施錠信号（GND に落とすと施錠するタイプ）。＋を信号線、−を GND へ。線は配線図か取付店で必ず確認する |
|  | OUT2〜OUT4 + / − | 汎用。作業灯などはリレーモジュールの入力につなぐ（直接は駆動できない） |
| J3 | IN1 + / − | 例：ドアの開閉信号（スイッチが GND に落ちるタイプ）は、IN+ を「12V OUT」へ、IN− をドアの信号線へつなぐ |
|  | ACC + / − | ACC（キー ON で 12V）の線を ACC+ に、ACC− を GND に |
| J7 | CAN H / CAN L / GND | OBD-II コネクタの 6 番（CAN-H）、14 番（CAN-L）、4・5 番（GND）。市販の OBD-II 延長ケーブルを切って使うと楽 |
| J8 | GND 3V3 GPS RX / TX（上から） | NEO-6M など UART の GPS モジュール。GPS RX の端子をモジュールの RX に、GPS TX の端子をモジュールの TX につなぐ |
| J4 | GND 3V3 SCL SDA（上から） | OLED や温度センサー（BME280 など）。四角いパッドが GND |

## 組み立て

部品表は `bom.csv` です。部品番号は基板のシルク印刷と同じです。

1. 背の低い部品から順にはんだ付けします：抵抗 → ダイオード → フォトカプラ・MCP2562 → セラミックコンデンサ → トランジスタ → ピンソケット → ポリスイッチ → 電解コンデンサ → ブザー → 端子台 → DC-DC。
   ESP32 ボードの下になる部品（U9・C5・C6・R15）は、**ピンソケットより先に**付けてください。R15 だけは**横に寝かせて**付けます（ESP32 の下に入れるため）。
2. **向きのある部品に注意してください。**
   - ダイオード（D1〜D7）：立てて付ける。本体を丸いシルクの穴の上に立て、**帯（カソード）を上にして**、上から折り返した足を「K」の四角いパッドへ。
   - 電解コンデンサ（C1・C2）：長い足（＋）を、シルクの「+」がある四角いパッドに。
   - フォトカプラ（U2〜U8）：本体の 1 番ピンの丸印を、四角いパッドに合わせる。
   - OKI-78SR（U1）：1 番ピン（Vin）を四角いパッドに。
   - MCP2562（U9）：本体の 1 番ピンの丸印（切り欠き側）を四角いパッドに。
   - 2SC1815（Q1）：左のパッドから E-C-B。シルクの半円が本体の丸い側。足の並びが違うトランジスタは使わない。
   - 抵抗：立てて付ける。どちら向きでもよい（本体を丸いシルクの穴の上に立てる）。
   - ブザー（BZ1）：＋表示の足（長い足）を「+」の四角いパッドに。
3. **ESP32 を挿す前に**、J1 に 12V をつないで、J5 の 15 番ピン（いちばん下、ESP32 の VIN）と GND の間が約 5V になることをテスターで確認します。
4. ESP32 ボードは **USB コネクタが基板の下側（「USB side」の文字の方）**、VIN の列が左（J5）に来る向きで挿します。
5. ESP32 に USB で書き込むときは、J1 の 12V を外してください（両方から同時に給電しないため）。

## 作り直すとき

`./build.sh` は、生成のあとに DRC・ピン照合（`check_pins.py`）・部品の収まり（`check_mech.py`）・回路シミュレーション（`sim/`、ngspice が必要）・製造データ照合（`check_fab.py`）を実行し、1 つでも問題があれば止まります。

```
./build.sh   # 生成 → 検証（DRC・ピン・収まり・回路・製造データ）→ ガーバー/ドリル → zip → BOM → 原寸 PDF → プレビュー
```

KiCad 7（`kicad-cli` と Python の `pcbnew`）と numpy が必要です。部品の位置と接続先は `gen_pcb.py` の上の方にまとめてあります。
配線は簡易オートルーターで引いているので、部品を動かしたら必ず `./build.sh` で DRC を通してください。
